# TechTown Brand Guidelines Skill

A GitHub Copilot skill containing TechTown's brand and design system guidelines.

## What's Included

- **Color palette** — Primary, text, background, and special purpose colors
- **Typography** — Font family, weights, and sizes
- **Spacing & Layout** — Consistent spacing scale and grid system
- **Components** — Buttons, cards, sections, and icon styles
- **Logo assets** — SVG and PNG formats for various use cases

## Usage

This skill is automatically used by GitHub Copilot when creating UI components, styling pages, or generating marketing materials for TechTown projects.
